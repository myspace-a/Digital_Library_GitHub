Notes
- Use short, simple tasks so each day feels doable.
- Commit small changes to a branch and open a PR to Dev for practice.

How to use this template (web UI)
1. Open this file (templates/week-template.md) on the Dev branch.
2. Click the three dots or the file view and choose "Copy" or open and select all to copy the content.
3. Click Add file → Create new file.
4. Name the new file: docs/week-02.md (or docs/week-03.md etc.).
5. Paste the content and replace placeholders like {{WEEK_NUMBER}} and {{WEEK_TITLE}}.
6. Commit directly to Dev or create a branch and open a PR.

Tips
- Keep the filename consistent: docs/week-02.md, docs/week-03.md, etc.
- For repeatable tasks, reuse checklist items from this template.
