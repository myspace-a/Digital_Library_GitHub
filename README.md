# Learning Hub — Digital Library (Dev branch)

Welcome! This README is placed on the Dev branch where you will add files and work on the learning plan.

Purpose
- This repo is a beginner-friendly learning center for Git and GitHub.
- Use the Dev branch to create and edit files while you learn. The import branch keeps a copy of the old project data.

Short guide (for beginners)
1. Read the learning plan: LEARNING_PLAN.md (on the Dev branch).
2. When you want to make a change, create a small branch from Dev (for example: my-change), edit files, and open a Pull Request to merge into Dev.
3. After you finish exercises on Dev, we can merge changes to the default branch when ready.

Branches in this repo
- main (default): the current default branch (kept for now).
- Dev: your working branch for the learning plan and new code (this README is here).
- import: backup of the older project files (do not delete until you are sure).

Helpful tips
- Use the GitHub web UI to create files and commits if you are a beginner.
- Keep commits small and add a clear message (example: "Add week-01.md with checklist").
- If you are not sure, keep a branch and open a Pull Request — that way changes can be reviewed and merged safely.
